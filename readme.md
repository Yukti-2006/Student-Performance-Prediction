Student Exam Score Prediction | Python, pandas, scikit-learn, Jupyter

Built a regression model to predict student exam scores from 19 academic, family and lifestyle factors across 6,600+ records.
Cleaned the data by imputing missing values, encoding ordinal and binary features, and removing invalid scores.
Compared Linear Regression, Ridge, Random Forest and Gradient Boosting using 5-fold cross-validation, and tuned the best model with RandomizedSearchCV.
Achieved R² of 0.74.
Identified attendance, hours studied and previous scores as the strongest predictors of performance.
